تثبيت وِرد على الهاتف
1) ارفع محتويات هذا المجلد كما هي إلى أي استضافة ثابتة بروابط https (مثل Netlify Drop أو GitHub Pages أو Cloudflare Pages).
2) افتح الرابط في الهاتف: أندرويد (كروم) ← تثبيت التطبيق. آيفون (سفاري) ← مشاركة ← إضافة إلى الشاشة الرئيسية.
3) بعد أول فتح يعمل التطبيق دون إنترنت.
لإخراج ملف APK لأندرويد: ضع رابط موقعك في pwabuilder.com واختر Android.
